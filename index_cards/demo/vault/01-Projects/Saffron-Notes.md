# Saffron-Notes

## Overview
Saffron-Notes is a small note-taking tool I want for quick capture plus linking, basically a lightweight take on a personal knowledge base. Core idea: plain text files on disk, fast full-text search, and backlinks computed on demand instead of stored in a database. Keeping the data model dumb on purpose so notes stay portable. Want a CLI first, then maybe a tiny local web view later. Main goals are speed, no lock-in, and easy export. Not trying to compete with anything, just scratching my own itch and getting more comfortable with functional design.
