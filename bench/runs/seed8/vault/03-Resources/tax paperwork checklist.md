# tax paperwork checklist

Reference for when filing season rolls around. Start gathering in January, don't wait for the deadline panic.

## Income docs

- W-2 from employer (usually lands by end of Jan, check the portal if paper is late)
- 1099-NEC / 1099-K for any freelance or side gigs
- 1099-INT and 1099-DIV from bank and brokerage, these trickle in until mid Feb
- 1099-B for stock sales. RSU/ESPP stuff often shows wrong cost basis, double check against the vesting statements
- Any crypto transaction export. Pull the full-year CSV before the exchange changes the format again
- Unemployment or state refund forms if applicable (1099-G)

## Deductions and credits

- 1098 for mortgage interest
- Property tax statement, grab from county site
- HSA statement (1099-SA and 5498-SA). Confirm contributions match what payroll reported
- IRA contribution confirmations, note the contribution deadline is the filing deadline, not Dec 31
- Charitable receipts, anything over $250 needs written acknowledgment
- Home office: square footage, utility totals, internet bill. Only works for self-employed income, not W-2
- Education: 1098-T if relevant
- Student loan interest (1098-E)

## Things I always forget

- Last year's return, need the AGI for e-file identity verification
- Estimated tax payments made during the year. Dig up the confirmation numbers and dates from each quarter
- Bank routing and account number for the refund/direct debit
- Health coverage form (1095-A if marketplace)
- State return needs separate docs if I moved mid-year
- Receipts for work gear I bought for the freelance side, keep in one folder

## Process notes

- Make a folder per tax year, scan everything as PDF with consistent names like `2026-1099-int-bank.pdf`
- Keep copies for at least 7 years
- Compare the final return against last year's. Big swings in any line mean something's off or something changed and I should know why
- File early if expecting a refund, wait closer to the deadline if owing (but still pay on time)
- If extending, the extension only delays the paperwork, not the payment. Estimate and pay by the original date
- Save the final PDF plus the e-file acceptance email
