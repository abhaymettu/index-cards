# keyboard shortcuts I keep forgetting

## macOS general
- `Cmd+Shift+.` toggles hidden files in Finder and in open/save dialogs. Saves me every time I can't find a dotfile.
- `Cmd+Option+Esc` force quit menu. Faster than hunting for the Apple menu when something is frozen.
- `Ctrl+Cmd+Space` emoji picker. Also works for symbols like arrows and ©.
- `Cmd+Shift+4` then Space turns the crosshair into a window capture. Hold Option to drop the shadow.
- `Cmd+backtick` cycles windows of the same app. Forget this constantly, then alt-tab through ten things.
- `Ctrl+Cmd+Q` locks the screen immediately.

## Terminal (zsh)
- `Ctrl+R` reverse history search. Press again to go further back.
- `Ctrl+A` / `Ctrl+E` jump to start / end of line.
- `Ctrl+W` deletes the previous word. `Ctrl+U` deletes everything before the cursor.
- `Ctrl+Y` pastes back whatever I just killed. Handy after an accidental `Ctrl+U`.
- `Option+Left/Right` word jump only works if the terminal is set to treat Option as Meta. Check the profile settings if it prints weird characters.
- `!!` repeats the last command, `sudo !!` for when I forgot sudo.
- `Ctrl+L` clears the screen without killing the current line.

## Editor
- `Cmd+D` selects the next occurrence of the current word. Keep pressing to add more cursors.
- `Cmd+Shift+L` selects all occurrences at once.
- `Option+Up/Down` moves the current line. Add Shift to duplicate it.
- `Cmd+Shift+O` go to symbol in file. `Cmd+T` go to symbol across the workspace.
- `Ctrl+G` jump to line number.
- `Cmd+K Cmd+0` folds everything, `Cmd+K Cmd+J` unfolds. Useful for skimming a huge file.
- `F2` rename symbol, way better than find and replace.

## Browser
- `Cmd+Shift+T` reopens the last closed tab. Can press repeatedly.
- `Cmd+L` focuses the address bar.
- `Cmd+Option+I` opens devtools, `Cmd+Option+J` goes straight to the console.
- `Cmd+Shift+C` in devtools is the element picker.
- `Cmd+Shift+R` hard reload, bypasses cache.

## Tmux
- Prefix is `Ctrl+B`, then `%` splits vertically, `"` splits horizontally.
- Prefix `z` zooms a pane to full screen and back.
- Prefix `[` enters copy mode, `q` exits.
- Prefix `d` detaches. `tmux a` reattaches.

## Notes to self
- Learn one new shortcut a week instead of cramming. Stick it on a sticky note near the monitor until it sticks.
- If I look something up twice in a month, it goes in this note.
