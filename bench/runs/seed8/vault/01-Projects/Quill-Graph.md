# Quill-Graph

## Overview
Quill-Graph is a small tool for turning my scattered markdown notes into a queryable graph. It parses links, tags, and headings, then stores them as nodes and edges so I can ask things like "what touches this idea?" or "which notes are orphans?" Goal is a fast CLI first, maybe a simple visual explorer later. Keeping the data model plain (EDN) so it's easy to inspect and diff. Not trying to replace the editor, just add a layer of insight on top.
