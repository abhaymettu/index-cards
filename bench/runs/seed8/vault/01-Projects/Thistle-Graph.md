# Thistle-Graph

## Overview
Small graph library/engine for tracking dependencies between my notes and code modules. Idea is to parse a folder of markdown and source files, build an in-memory graph of links, and answer queries like "what breaks if I move this?" fast, with no heavy runtime. Keeping allocations explicit and the binary tiny is the whole point. Want a CLI first, maybe a simple export to DOT after that. Still rough, mostly sketching data structures (adjacency list vs. compact edge array) and deciding how to handle cycles.
