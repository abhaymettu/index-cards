# Iris-Forge

## Overview
Iris-Forge is a small Python toolchain for turning raw image batches into cleaned, labeled datasets. Main idea: watch an intake folder, dedupe, normalize sizes/color profiles, then queue anything ambiguous for quick manual review. Goal is to stop hand-rolling one-off scripts every time a new batch lands. Keep it boring and scriptable first, maybe a thin CLI after. Review UI is a stretch, not v1.
