# Vesper-Maps

## Overview
Offline-first mapping app for Android that caches vector tiles and lets me plan routes without signal. Main goal is fast tile loading on older phones and small storage footprint. Also want saved places and custom layers, but only after the core renderer is stable. Keeping scope tight so the June date is realistic.
