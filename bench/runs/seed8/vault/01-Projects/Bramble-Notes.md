# Bramble-Notes

## Overview
Bramble-Notes is a small native notes app for Apple platforms that I want to actually use daily. Core idea: plain markdown files on disk, fast full-text search, and backlinks that don't need a database server or any cloud account. Sync is just a folder, so it plays nice with whatever I already use. Keeping scope tight on purpose: editor, link graph, quick capture, and tag filtering. No plugins for v1. Main goal is something snappy that opens instantly and never traps my data in a weird format.
