# Pebble-Notes

## Overview
Small local-first note tool, written in Clojure. Idea is quick capture: drop a thought in, tag it later, nothing blocks on sync. Plain text files on disk, a tiny index for search, and a REPL-driven workflow so I can poke at stuff while it runs. Not trying to replace Obsidian, more like a scratch layer that feeds into it. Keep the core small, push anything fancy to plugins. Want something usable daily before polishing anything.
