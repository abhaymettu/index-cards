# Umber-Notes

## Overview
Umber-Notes is a local-first notes app for people who live in markdown. Main idea: fast full-text search, backlinks that don't choke on big vaults, and a plain-files storage model so nothing is locked in. Want sync to be optional and dead simple, conflict handling visible instead of silent. Keeping the scope small at first: editor, search, link graph. Plugins come later if the core feels solid. Mostly scratching my own itch since existing tools get sluggish past a few thousand notes.
