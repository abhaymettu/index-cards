# Willow-Ledger

## Overview
Small personal ledger tool for tracking shared expenses and recurring bills in one place. Goal is a fast CLI plus a tiny local web view, with data kept in plain files so nothing gets locked in. Main pain it fixes: reconciling monthly splits by hand in spreadsheets. Want import from CSV bank exports, simple tagging, and a monthly summary that actually matches what I paid. Keep scope tight, no accounts, no sync service for now. Ship something usable before polishing anything.
