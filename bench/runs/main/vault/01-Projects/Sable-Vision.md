# Sable-Vision

## Overview
Sable-Vision is a small computer-vision tool for flagging visual regressions in web UIs. It captures screenshots from CI runs, diffs them against approved baselines, and highlights changed regions so review is quick. Main goal is cutting down on noisy diffs (anti-aliasing, font rendering, animation timing) so people actually trust the output. Want a tight CLI first, maybe a tiny web viewer later. Keep scope small, ship something usable before polishing.
