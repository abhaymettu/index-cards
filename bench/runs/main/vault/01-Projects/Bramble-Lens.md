# Bramble-Lens

## Overview
Bramble-Lens is a small tool for tracing why an Android app's UI state ends up the way it does. It records state changes and events as they flow through the app, then lets me replay them step by step on a timeline. The main goal is cutting down the time I burn on "how did it get here?" bugs. First pass is a logging layer plus a simple viewer. Anything fancier, like diffing two sessions, only if the basics feel solid. Keep scope tight, ship something usable before adding features.
