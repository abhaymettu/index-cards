# Fjord-CI

## Overview
Fjord-CI is a lightweight CI runner I want for small side projects. Existing hosted CI is slow to start and annoying to debug, so this one runs pipelines defined in a tiny config file, caches deps aggressively, and streams logs live to the terminal. Goal is sub-10s cold start for a typical Node build. Keep the scope small: no plugin system in v1, just jobs, steps, and artifacts. If it works well I'll dogfood it on my own repos first.
