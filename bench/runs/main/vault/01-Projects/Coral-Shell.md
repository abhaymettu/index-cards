# Coral-Shell

## Overview
Coral-Shell is a small, fast command-line shell I'm building to replace my clunky dotfile-heavy setup. Main goals: quick startup, sane pipelines, and readable scripting syntax without the usual quoting headaches. Want built-in job control, history search that doesn't suck, and a plugin hook for custom prompts. Keeping the core tiny so it stays easy to reason about and debug. Mostly a learning project, but I'd like to daily-drive it by the target date.
