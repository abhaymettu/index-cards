# Quill-Vision

## Overview
Quill-Vision is a tool for turning screenshots and photos of handwritten notes into clean, searchable markdown. Idea is to run OCR on the image, then clean up layout (headings, bullets, rough tables) so it drops straight into the vault without much manual fixing. Want it fast enough to use on a whole page in a couple seconds. Main risks: messy handwriting and mixed-language scribbles. First milestone is a CLI that takes one image and spits out a .md file. After that, maybe a small watch-folder mode so new images get processed automatically.
