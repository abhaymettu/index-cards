# Hollow-Sync

## Overview
Hollow-Sync is a small sync engine for keeping notes and config files consistent across my machines without a central server. Idea: devices exchange only diffs over a local network or a relay, merge conflicts get resolved with simple per-file rules, and everything stays readable on disk. Goal is boring and reliable, not clever. Offline-first, resumable transfers, and a clear log of what changed and why. If the core loop works I'll think about a mobile client later, but not before the desktop path is solid.
