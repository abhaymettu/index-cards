# meditation log

## current setup
- 10 min, right after coffee, before opening laptop. If I open laptop first it never happens
- cushion on the floor by the window, phone on airplane mode face down, timer set to a soft bell
- eyes half open, gaze on the floor about a meter ahead. fully closed = I drift into planning mode or nap
- breath counting 1–10 then restart. lose count = restart at 1, no commentary

## what actually helps
- sitting at the same time daily matters more than length. 5 min every day > 20 min twice a week
- two slow exhales before starting, settles the jaw and shoulders
- noticing the jaw clench is a good anchor. I clench when thinking about work stuff
- if mind is racing, switch to listening to ambient sound instead of breath. works better than forcing the count
- walking version (10 min around the block, no podcast) counts on bad days

## recurring problems
- **drafting code in my head.** happens almost every sit. label it "planning," return to breath. don't try to solve it. if the idea is actually good, I'll still remember it after
- **sleepy afternoons sits.** skip them or do standing. lying down is a trap
- **itchy/restless around minute 6–7.** usually peaks then fades if I don't move. moving once is fine, just do it slowly
- **judging the session** afterward ("that was bad"). there's no bad one, only sat or didn't sit
