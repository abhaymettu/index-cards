# keyboard shortcuts I keep forgetting

## macOS system

- `Cmd+Shift+4` then `Space` → screenshot a whole window, not a region. Hold `Option` on click to drop the shadow.
- `Cmd+Shift+5` → screen recording menu. Easier than hunting QuickTime.
- `Cmd+Option+Esc` → force quit dialog.
- `Ctrl+Cmd+Space` → emoji picker. Also works in terminal prompts sometimes.
- `Cmd+Shift+.` in Finder/open dialogs → toggle hidden files. Saves me from going to terminal every time.
- `Cmd+Ctrl+Q` → lock screen instantly.

## zsh / terminal line editing

- `Ctrl+A` / `Ctrl+E` → start / end of line
- `Ctrl+W` → delete previous word
- `Ctrl+U` → kill whole line (zsh kills entire line, bash only to cursor)
- `Ctrl+R` → reverse history search, hit again to cycle older matches
- `Option+Left/Right` → jump by word (needs "Use Option as Meta" turned on in terminal prefs)
- `Ctrl+X Ctrl+E` → open current command in $EDITOR. Great for long pipelines.
- `!!` → rerun last command, `sudo !!` when I forgot sudo
- `Alt+.` → paste last argument of previous command. Repeat to go further back.

## editor (VS Code)

- `Cmd+D` → select next occurrence. `Cmd+K Cmd+D` skips one.
- `Cmd+Shift+L` → select ALL occurrences of current selection
- `Option+Up/Down` → move line. Add `Shift` to duplicate it.
- `Ctrl+G` → go to line
- `Cmd+Shift+O` → jump to symbol in file; `Cmd+T` for symbol across workspace
- `F2` → rename symbol (way better than find/replace)
- `Cmd+B` → toggle sidebar. `Ctrl+backtick` → toggle terminal.
- `Cmd+K Z` → zen mode

## browser

- `Cmd+Shift+T` → reopen closed tab
- `Cmd+L` → focus address bar
- `Cmd+Option+I` → devtools. `Cmd+Option+J` goes straight to console.
- In devtools: `Cmd+Shift+P` → command menu, like a palette. Good for "screenshot full size" and "disable cache".
- `Cmd+Shift+C` → inspect element picker

## notes to self
