# keyboard shortcuts I keep forgetting

Writing these down so I stop googling them every other week. Mac unless noted.

## macOS general

- `Cmd+Shift+.` toggles hidden files in Finder and in file open dialogs. Saves me constantly.
- `Cmd+Option+Esc` force quit menu. Faster than hunting for the Apple menu.
- `Ctrl+Cmd+Space` emoji picker. Also works for special symbols like arrows.
- `Cmd+Shift+4` then `Space` captures a single window with the shadow. Hold `Option` when clicking to drop the shadow.
- `Cmd+~` cycles windows of the same app. Not the same as `Cmd+Tab`, easy to mix up.
- `Cmd+Shift+G` in Finder to type a path directly.

## terminal / zsh

- `Ctrl+A` / `Ctrl+E` jump to start / end of line.
- `Ctrl+W` kills previous word. `Ctrl+U` kills to start of line. `Ctrl+K` kills to end.
- `Ctrl+R` reverse history search, press again to go further back. `Ctrl+G` bails out cleanly.
- `Option+Left/Right` word jump only works if the terminal sends the right escape codes. Had to turn on "Use Option as Meta" in the terminal prefs.
- `Ctrl+L` clears screen but keeps scrollback. `Cmd+K` wipes scrollback too.
- `!!` reruns the last command, `sudo !!` when I forgot sudo (again).
- `Ctrl+Z` suspends, `fg` brings it back. Forget this one when vim hangs around in the background.

## editor (VS Code style)

- `Cmd+D` adds next match to the selection. `Cmd+Shift+L` selects all matches.
- `Option+Up/Down` moves line. Add `Shift` to duplicate it instead.
- `Ctrl+G` go to line number.
- `Cmd+P` quick open file, then type `:42` to jump to a line. `@` for symbols in the file, `#` for symbols across workspace.
- `Cmd+Shift+P` command palette. Most things I can't remember live here.
- `Cmd+.` quick fix / code actions. Underrated.
- `F2` rename symbol, way safer than find and replace.
- `Ctrl+-` go back to the previous cursor location. Super handy after jumping to a definition.

## browser

- `Cmd+Shift+T` reopen closed tab. Can press repeatedly.
- `Cmd+L` focus address bar.
- `Cmd+Option+I` devtools, `Cmd+Shift+C` element picker directly.
- `Cmd+Shift+R` hard reload, skips cache.
