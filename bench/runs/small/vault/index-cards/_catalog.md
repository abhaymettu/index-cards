# Index cards

One card per person, project, harness, area and topic, each with a dated Timeline of every note, report and (on project cards) session that mentions it. Rebuilt by the indexer. To add a thing that has no note, or fix a noisy match, edit [[index-cards/_registry|_registry]]. A bullet you write on a card ends with `[source: <ref>; added: YYYY-MM-DD]` (a `k:` Timeline key, a note path or a URL); `indexer.py --unsourced` lists the ones that do not.
